Developed a full-stack task management web application using the MERN stack (MongoDB, Express.js, React.js, Node.js) to help users create, track, update, and delete daily tasks with deadlines and priorities.

1. Designed and implemented RESTful APIs for user registration, authentication (using JWT and bcrypt), and task CRUD operations in Node.js + Express.js

2. Built a responsive and dynamic React.js frontend using React Hooks, integrated with backend APIs for seamless task handling

3. Used MongoDB with Mongoose to define and manage schema-driven task and user data

4. Implemented secure authentication/authorization workflows with role-based access control

5. Structured the app with modular folders for frontend and backend separation, enabling scalable development

6. Applied best practices for code organization, error handling, and API status management

7. Managed version control and collaboration via Git and GitHub
